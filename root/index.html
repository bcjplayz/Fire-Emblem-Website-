Fire Emblem: Awakening released in April 2012 for the Nintendo 3DS.

Fire Emblem Awakening is widely credited with saving the franchise because Nintendo had issued an ultimatum to the developer, Intelligent Systems: sell at least 250,000 copies, or the series would be cancelled. The developers obviously didn't want this, so they added every single feature they could think of including.

Awakening is a tactical role-playing game that features turn-based combat on a gridlocked map.
